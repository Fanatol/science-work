# lab1 — Температурная компенсация ультразвукового дальномера

**Вариант:** 8 (повышенный уровень)
**Группа:** ПИЖ-б-о-25-2
**Команда:** Лещинский Павел, Романов Даниил, Степанян Даниел

## О работе

Исследование влияния температуры воздуха на точность ультразвукового измерения расстояния. Реализована температурная компенсация на Arduino Uno с датчиками HC-SR04 и DS18B20.

## Оборудование

| Компонент | Назначение |
|-----------|------------|
| Arduino Uno | Микроконтроллер |
| HC-SR04 | Ультразвуковой дальномер |
| DS18B20 | Цифровой термометр |
| Резистор 4.7 кОм | Подтяжка 1-Wire |

## Подключение

| Датчик | Пин датчика | Пин Arduino |
|--------|-------------|-------------|
| HC-SR04 | VCC | 5V |
| HC-SR04 | Trig | D9 |
| HC-SR04 | Echo | D10 |
| HC-SR04 | GND | GND |
| DS18B20 | VCC | 5V |
| DS18B20 | DQ | D2 |
| DS18B20 | GND | GND |
| Резистор | между DQ и 5V | — |

## Формулы

```text
v = 331.3 + 0.606 × T
D_raw  = duration × 343.0 / 2 / 10000
D_comp = duration × v     / 2 / 10000
Δ = D_raw − D_comp
E = Δ / D_comp × 100%
